# Core Rules — Business Plan Engine

> Distilled from this engine's own `CLAUDE.md`.

## Never fabricate a number

Financial projections require explicit, stated assumptions. Market data is
either sourced or clearly flagged as an estimate. A plausible-looking number
with no traceable basis is worse than an explicit "estimate, unsourced" label —
the second is honest, the first misleads a reader who cannot tell the
difference.

## Never accept cost-plus or competitor-match pricing without the audit

A plan's pricing section does not pass with bare cost-plus or
competitor-matching logic. Run the 9 Failures audit and the 5 Propositions
stack (`meta-pricing-strategy`) before pricing is considered done.

## Ask for business name, industry, and country context first

Every plan starts by establishing this triple before any drafting — country
context changes regulatory, market, and financial-modelling assumptions
throughout the document, so establishing it late means rework.

## Cross-reference sections for consistency

Each section of a plan should reference the sections it depends on or affects.
A plan whose market-sizing section and financial-projections section imply
different growth assumptions has failed internal consistency even if each
section is individually well-written.
