# Agent Bankability Checklist — Meta-Level Reference

When the plan is an agent business, use the full agent bankability scorecard at:

`skills/meta-agent-bankability-and-investor-readiness/references/saas-agent-bankability-checklist.md`

That scorecard covers 7 dimensions, max 100 points:

1. Unit-economic discipline (0-15) — cost-per-resolved-task; agent GM; sensitivity; stress; reserves
2. Moat-vs-wrapper (0-15) — 8-question rubric; wrapper detector; foundation-model commoditisation; Wardley placement; defensibility score
3. Governance maturity (0-15) — action taxonomy; HITL policy; kill-switch drilled; audit-log regulator-acceptable; drill cadence
4. Safety / red-team practice (0-15) — AI Safety Lead in seat; Class C/D eval coverage; injection / jailbreak / auth-bypass coverage; incident log; insurance
5. Regulatory readiness (0-10) — engagement; sectoral approval; HITL policy regulator-aligned; DPIA
6. Talent depth (0-15) — Agent Architect; Tool; Eval; AI Safety; HITL Designer; FDE
7. KPI maturity (0-15) — cost per resolved tracked; intervention rate tracked; success rate tracked; irreversibility log; living-plan cadence; variance thresholds

## Interpretation

- 0-39: not bankable for institutional agent fund
- 40-59: bankable for grant / DFI / strategic
- 60-79: bankable for Series A / institutional agent fund
- 80-94: top-quartile investor-ready
- 95-100: rare; growth-round ready
