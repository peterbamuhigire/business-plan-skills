# Executive Summary — Agent Block (Template)

Use this block in the executive summary of any agent-product plan. Sits after the standard SaaS / AI exec-summary content.

```
## Agent product overview

### Archetype
We are a {single-agent customer-service / single-agent operations / multi-agent orchestrated / vertical agentic SaaS / agent platform} business.

### Customer job
We act on behalf of {customer type} to {primary outcome}, replacing {prior human / software approach}.

### Headline economics
- Cost per resolved task: {USD x.xx}; competitive anchor: {USD x.xx}
- Agent gross margin: {x%}
- Intervention rate: {x%}; trajectory: {declining / stable / rising}
- Task success rate: {x%}; trajectory: {declining / stable / rising}
- Agent ARR: {USD k} ({x% of total ARR})
- Agent ARR growth: {x% YoY}

### Autonomy ladder
Currently at {assist / suggest / supervise / agentic} for {Class A / B / C / D} actions; next promotion to {next rung} on {milestone}.

### Moat thesis (one paragraph; plain English; not marketing language)
{Our moat is X because Y, evidenced by Z. If foundation model providers commoditise A, what survives is B, C, D, evidenced by E. Customer switching cost is F because of G accruing per customer at rate H.}

### AI Safety and governance
AI Safety Lead in seat: {yes / no / fractional}. Kill-switch drilled monthly. Audit-log {regulator-accepted / pending acceptance}. Drill cadence: monthly safety drill + quarterly tabletop. Latest sev-1 incident: {date / none in last 12 months}.

### Regulatory posture
Engaged with {regulators / sectoral bodies}. Sectoral approval: {status}. Data residency: {in-region / hybrid / cross-region}.

### Funding ask and milestones
Raising {USD k} at {pre-money USD k}, primary use of proceeds: Tool Engineering, Eval, AI Safety, GTM. Milestones to next round: {specific agent-level milestones}.

### Bankability and valuation
Agent bankability score: {n / 100}. Adjusted multiple range: {Nx-Mx ARR}. SaaS base x AI adjustment x agent adjustment x geographic adjustment.
```

## Notes for the author

- One page max for executive summary; this block fits within standard exec-summary length
- The archetype must be declared on page one
- Headline economics must include cost-per-resolved-task; investors quote this number
- The moat thesis paragraph must be written in plain English without marketing language; if it reads as marketing, rewrite
- AI Safety Lead status is non-negotiable to state
- Funding ask + milestones must reconcile with Section 11
- Bankability score and adjusted multiple must reconcile with bankability + valuation work
