## 2. Stage-by-Stage Playbook

### Pre-seed (USD 250k-1.5M)

- **What you show:** Demo of one agent; eval suite v0; cost-per-resolved baselined; first 1-5 design partners; fractional or part-time AI Safety Lead; tool registry started
- **Use of proceeds:**
  - Agent Architect + Tool Engineer + Eval Engineer: 50-60%
  - Compute / LLM / tools: 15-20%
  - GTM (design-partner-led, no scaled sales): 10-15%
  - AI Safety (fractional / advisor): 5-10%
  - Reserve: 5%
- **Round duration:** 8-16 weeks from open to close
- **Diligence depth:** light; founder-led
- **Likely investors:** angels, agent-specialist micro-funds, accelerators, African / EM seed pre-seed (Future Africa, Antler, MEST, Catalyst Fund, Ingressive)

### Seed (USD 1.5-5M)

- **What you show:** One Class B agent live with 5-20 customers; cost-per-resolved trending; eval suite v1; first cost-engineering wins; moat thesis paragraph; agent GM trajectory
- **Use of proceeds:**
  - Tool Engineering: 25-30%
  - Eval Engineer + AI Safety: 15-20%
  - Agent Architect + senior eng: 15-20%
  - Compute / infra: 10-15%
  - GTM (founder-led + first AE / SE): 10-20%
  - HITL + Forward Deployed (if applicable): 5-10%
  - Reserve: 5%
- **Round duration:** 12-20 weeks
- **Diligence depth:** moderate; eval + cost data + customer references
- **Likely investors:** agent-specialist seed funds, AI-specialist seed (a16z AI scout, Bessemer AI), African seed (TLcom, Norrsken22, Partech, Ventures Platform, 4Di, Knife), DFI seed envelopes

### Series A (USD 5-20M)

- **What you show:** Class C agent live in supervised mode; cost-per-resolved under target; 20-100 customers; agent GM >50%; AI Safety Lead full-time; bankability score >60; first regulator engagement; clear path to Class D human-final
- **Use of proceeds:**
  - Tool Engineering team: 25-35%
  - Eval team + AI Safety team: 15-20%
  - GTM (sales team formation): 20-30%
  - Forward Deployed (if vertical thesis): 5-15%
  - Compute / infra: 8-12%
  - HITL operations: 5-10%
  - Reserve: 5-8%
  - Regulator / compliance: 3-5%
- **Round duration:** 12-24 weeks
- **Diligence depth:** rigorous; technical DD; cost / eval / governance review; customer references
- **Likely investors:** agent-specialist A funds (Index, a16z, Bessemer, Sequoia AI, Lightspeed agent, Founders Fund), vertical AI funds (sector-anchored), generalist SaaS with AI thesis, sovereign-AI strategic, DFI A envelopes

### Series B (USD 20-60M)

- **What you show:** Class D agent live with human-final; eval coverage >95% on Class C/D; cost-per-resolved well under competitive anchor; agent GM >60%; 100+ customers or anchor regulated / public-sector; first audit clearance; multi-country pilot
- **Use of proceeds:**
  - GTM scale: 30-45%
  - Engineering scale: 20-30%
  - Forward Deployed scale: 10-15%
  - AI Safety + governance team: 8-12%
  - International expansion: 10-15%
  - Reserve: 5-8%
- **Round duration:** 16-28 weeks
- **Diligence depth:** rigorous + commercial DD + financial DD + audit
- **Likely investors:** agent-specialist growth, vertical AI growth, generalist growth, sovereign-AI at scale, DFI patient capital, strategic

### Growth (USD 60M+)

- **What you show:** Multi-country deployment; multi-vertical or platform play; agent GM >70%; sovereign-AI procurement won; regulator-accepted audit-log in production; strategic-acquisition or IPO-track
- **Use of proceeds:**
  - GTM and international: 40-55%
  - Platform / multi-vertical engineering: 20-25%
  - AI Safety + governance + regulator team: 5-8%
  - M&A: 5-15%
  - Reserve + working capital: 10%
- **Round duration:** 20+ weeks
- **Diligence depth:** investment-banking-grade DD
- **Likely investors:** generalist growth, strategic, sovereign-AI strategic, late-stage SaaS funds, crossover funds, potential pre-IPO investors

## 3. Milestone Breakpoints Summary

| From | To | Mandatory milestones |
|---|---|---|
| Pre-seed | Seed | Class B agent live; 5+ customers; eval v1; cost-per-resolved baselined; AI Safety engaged |
| Seed | A | Class C supervised; eval >85%; cost-per-resolved on target; 20+ customers; agent GM >50%; AI Safety Lead full-time; bankability >60 |
| A | B | Class D with human-final; eval >95% on C/D; cost well under anchor; agent GM >60%; 100+ customers or regulated anchor; first audit clearance |
| B | Growth | Multi-country; multi-vertical / platform; agent GM >70%; sovereign-AI procurement won; regulator-accepted audit-log; multi-year ARR growth path |
| Growth | Exit | Category-defining; multiple sovereign tenders; strategic-acquisition value or IPO path; full bankability >85 |

## 5. Investor-Narrative Discipline

Open the deck / memo / data room with:

1. **Agent thesis paragraph** — archetype declared (single-agent / multi-agent / vertical / platform); customer-job; autonomy ladder position; cost-per-resolved-task; moat thesis in one paragraph
2. **Headline economics** — agent GM trajectory; cost-per-resolved trajectory; intervention rate trajectory; task success
3. **Moat-vs-wrapper** — 8-question rubric score; what survives if foundation provider commoditises
4. **Autonomy ladder progress** — current rungs; gates passed; next promotion
5. **Regulator engagement** — sectoral and data-protection regulator status
6. **AI Safety Lead and team** — in seat; succession; retention
7. **Stress tests** — provider 5x; tool outage; intervention 2x; irreversibility incident; FX
8. **Use of proceeds** — by line with %
9. **Milestones to next round**
10. **Bankability score** with subscores

## 6. Anti-Patterns

- Treating agent funding as ordinary SaaS funding (shape is wrong)
- Skipping bankability evidence before round opens
- Round size sized to runway not to milestone gate
- "AI fund" generic; should specify agent appetite
- DFI as primary at stages where DFI cycle is too slow
- Sovereign-AI as primary without local-entity / local-citizen evidence
- Pricing local currency to USD investors
- Cap-table concentration with single strategic at growth (lock-in risk for next round)

## 7. Living-Plan Wiring

- Quarterly investor target list refresh
- Monthly milestone progress
- Quarterly bankability rescore
- Round opens -> set use of proceeds
- DFI cycle alignment if applicable
