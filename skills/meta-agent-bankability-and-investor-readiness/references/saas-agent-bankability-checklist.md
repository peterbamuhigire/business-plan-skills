## Aggregate Scoring

- 7 dimensions, max 100
- 0-39: not bankable for institutional agent fund; remediation required
- 40-59: bankable for grant / DFI / strategic
- 60-79: bankable for Series A / institutional agent fund
- 80-94: top-quartile investor-ready
- 95-100: rare; growth-round ready

## Evidence Inventory Template

For each item scored above, document:
- Evidence type (artefact name)
- Location (data-room link / file path)
- Owner
- Last updated
- Reviewer

## Remediation Plan Template

For each binding gap:
- Gap description
- Target score (after remediation)
- Concrete actions (3-5 specific steps)
- Owner
- Deadline
- Cost / investment required
- Dependency on other workstreams
