# Agent Data-Room Contents — Reference

The agent-specific data-room sections that institutional agent-fund partners and DFI risk officers expect in 2026. Append to the standard SaaS / AI data-room contents.

## 1. Agent product

- Agent architecture document (planner / worker / critic; tool registry; channels; data flows)
- Action taxonomy with irreversibility classes A/B/C/D
- Autonomy ladder per customer job (current rung; gates passed; next promotion)
- Roadmap by ARR milestone
- Build / buy / host posture per layer
- Model-router architecture
- Channel coverage (WhatsApp / USSD / SMS / IVR / web / voice / mobile-money)
- Local-language coverage (if applicable)

## 2. Agent unit economics

- Cost-per-resolved-task computation with full waterfall
- Agent gross margin (current + trajectory)
- Sensitivity analysis (volume / pricing / intervention / FX / failure / cache)
- Stress analysis (provider 2x / 5x; tool outage; intervention 2x; irreversibility; FX; foundation deprecation; branch explosion; regulator freeze)
- Reserve register (irreversibility / migration / regulator) with adequacy
- Calculator workbook (or Notion / Python notebook equivalent)

## 3. Agent pricing

- Pricing primitive and decision rationale
- Pricing schedule (per-resolution / per-outcome / per-step / per-agent / hybrid)
- Intervention-credit policy
- SLA schedule with credits
- Vendor-cost pass-through clause (sample contract excerpt)
- Price corridor analysis
- Customer pricing examples (anonymised)

## 4. Agent moat-vs-wrapper

- 8-question rubric score with evidence per dimension
- Wrapper-risk detector outcome
- Foundation-model commoditisation analysis (what survives)
- Wardley-map placement of agent components
- Moat thesis paragraph
- Action-data accrual evidence (volume; trajectory; improvement attribution)
- Tool-registry inventory (proprietary vs commodity)

## 5. Agent eval and governance

- Eval suite documentation (offline + online; sample rate; human-correction loop)
- Eval score history (trend by metric)
- Eval coverage by action class
- Red-team / drill cadence with attendance records
- Kill-switch design + drill records
- Audit-log spec (immutability; retention; queryability; regulator-acceptance evidence)
- Incident log (sev-1 / sev-2 last 24 months; postmortems)
- Customer-credit / indemnity history

## 6. Agent risk register

- Populated risk register across 12 categories
- Stress-test scenarios with quantified impact
- Reserve sizing
- Insurance coverage review (with gaps)
- Drill calendar and attendance

## 7. Agent talent

- Org chart with mandatory roles
- AI Safety Lead bio + retention evidence
- Eval Engineer / Agent Architect / Tool Engineer / HITL Designer in seat
- Compensation bands by role
- Retention plan
- Succession plan for AI Safety Lead
- African talent map (where applicable)

## 8. Regulator engagement

- Regulator-engagement log (KE ODPC / NG NDPC / UG NITA-U / ZA Info Reg / NCSA / sectoral)
- Sectoral approvals (or documented path)
- DPIA / data-protection impact assessment
- HITL policy documentation
- Audit-log acceptance evidence
- Sovereign-AI procurement readiness (where applicable)

## 9. Agent sustainability and ethics

- Action-accountability declaration
- Human-final policy on Class D
- Contestability / redress workflow
- Jobs-impact disclosure (where applicable)
- Sustainability KPIs (energy per resolved task; cache-hit; in-region inference)
- Training-data provenance audit
- Downstream-misuse controls
- External-review / certification posture

## 10. Agent customer evidence

- Customer references (resolved-task volumes; cost savings; SLA metrics)
- Customer renewal / NRR by cohort
- Pricing realisations vs list
- HITL escalation rates per customer
- Audit / regulator references from customers (where applicable)
- Case studies with quantified outcomes

## 11. Agent comparable transactions

- Comparable rounds and exits scan
- Valuation adjustment trail (SaaS base x AI adjustment x agent adjustment x geographic)
- Stress on valuation under tail risks
- Investor-archetype-specific multiples

## 12. Agent bankability

- Agent bankability scorecard (7 dimensions; 100 max)
- Evidence inventory per scorecard item
- Remediation plan for binding gaps
- Cross-reference to all sections above

## 13. Living-plan governance

- Cadence calendar (weekly / monthly / quarterly / annual)
- Decision log extract (last 12 months)
- Trigger-replan events log
- MSPOT artefact (annual)
- Variance diagnoses for off-plan KPIs

## 14. Africa-specific (where applicable)

- Country-context map
- Multi-country regulator engagement
- Sovereign-AI procurement footprint
- Local-language coverage
- FX corridor evidence
- Channel-mix evidence
- Public-sector contract terms (where applicable)
- DFI / multilateral co-investment letters

## Notes

- The agent data room sits on top of the standard SaaS / AI data room; do not duplicate
- Sensitive material (customer references, regulator correspondence) under NDA
- Update quarterly; stale data rooms hurt diligence velocity
- Single canonical version-of-truth; no parallel versions
- Owner: CFO + Compliance + AI Safety Lead jointly
