# Kaizen Experiment and Learning Reference

Use for market validation, business-plan assumptions, product/market-fit work, and living-plan reviews.

For each material assumption, record: assumption, evidence, confidence, reversible test, expected signal, decision threshold, guardrail, owner, timebox, result, and next action. Prefer small tests that reduce uncertainty before committing scarce capital. A metric is not learning until it changes a decision.

Use the PDCA/Build–Measure–Learn sequence: define the problem and baseline; run the smallest ethical test; compare observed behaviour with the hypothesis; standardise, pivot, pause, or reject. Keep a counter-metric so local optimisation does not damage mission, quality, cash, staff capacity, or customer trust.

Book-informed inputs: Lean/Kaizen for incremental learning and waste reduction; XP 2026 for value retrospectives, experimentation, AI adoption, and UX pilots; the Nonprofit Guide for mission/stakeholder/board review; Facility Move for readiness, cutover, stabilisation, and closeout.
