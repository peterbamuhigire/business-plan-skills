# SaaS Board Pack & Investor Update Template

## A. Monthly Investor Update (1-2 pages)

Sent within 7 business days of month-close.

```
Subject: [Company] — [Month YYYY] Investor Update

Hi [investor names],

Highlights this month:
[ONE-LINE HEADLINE — the most important thing that happened]

KEY METRICS
- ARR: $X (vs $Y last month, +/-Z%; vs plan +/-W%)
- Net New ARR: $X
- Customers: N (+M new, -K churn, net +/-X)
- NRR / GRR: X% / Y%
- CAC Payback: X months
- Cash: $X (-Y burn this month; Z months runway)
- Rule of 40: X (growth %) + Y (margin %) = Z

WINS (3-5)
- [Customer win / product launch / hire / partnership / press]
- ...

LOSSES / RISKS (2-4, honest)
- [Lost deal / churn / hiring gap / technical risk]
- ...

ASKS — how investors can help
- [Specific ask 1 — e.g. intro to CFO at X company]
- [Specific ask 2 — e.g. advice on pricing decision]
- ...

FORWARD LOOK
- [What's the focus next month?]
- ...

Thanks,
[CEO]
```

## B. Quarterly Board Pack Structure (20-40 pages)

Sent 5 business days before board meeting.

### B.1 Cover + Agenda

```
[Company] Board Meeting
Date: [date]
Location: [in-person / Zoom / hybrid]
Attendees: [list]

PRE-READ: this board pack
RUNNING ORDER (90-120 min):
1. CEO opening (10 min)
2. Financial review (15 min)
3. Operating metrics review (15 min)
4. Strategic discussion topics (45 min — the meat)
5. HR / risk / approvals (10 min)
6. Executive session (15 min, no management)
```

### B.2 CEO Letter (2-4 pages)

Narrative covering:
- What worked this quarter
- What didn't work
- Strategic insights (customer / market / competitive)
- Decisions the board is asked to weigh

### B.3 Financial Dashboard (4-6 pages)

- P&L (current quarter, year-to-date, vs plan, vs prior year)
- Cash flow statement
- Balance sheet snapshot
- ARR waterfall (visualised)
- Unit economics: LTV, CAC, Payback, Gross Margin, NRR, GRR, Magic Number, Rule of 40, Burn Multiple, Quick Ratio
- 12-month runway and replan trigger

### B.4 Operating Metrics Dashboard (4-8 pages)

- Customer count by tier / segment
- Cohort retention matrix (logo + revenue)
- Pipeline (top of funnel, qualified, weighted)
- Sales attainment vs plan
- CSM health-score distribution (green / amber / red)
- NPS / CSAT
- Product engagement (DAU/MAU, key feature adoption)
- Support / SLA performance

### B.5 Strategic Discussion Topics (5-10 pages)

1-3 explicit decisions for the board:
- Decision title
- Context / background
- Options considered
- Recommendation with rationale
- What the board is being asked to decide / advise on

This is the highest-value part of the board meeting. Default everything else to pre-read; spend the meeting on these.

### B.6 HR / People / Culture (2-3 pages)

- Headcount vs plan
- Key hires / departures
- Performance / promotions
- Culture / engagement signals
- Compensation / equity refresh items
- DEI / employer-brand commentary
- ESOP allocations needing board approval

### B.7 Risk Register Update (1-2 pages)

- Top 5 risks with status (green / amber / red)
- New risks emerged this quarter
- Mitigations in flight
- Regulatory / compliance status

### B.8 Forward Look — Next Quarter (2-3 pages)

- Top 3 priorities
- Specific quarter-end metric targets
- Resource asks
- Material upcoming events (releases, contracts, milestones)

### B.9 MSPOT Status (1 page)

- Mission (confirmed)
- Strategy (any change?)
- Projects (status green/amber/red per project)
- Omissions (any temptation to break the list?)
- Tracking (KPI summary)

### B.10 Appendix

- Deeper financials (monthly P&L; cohort matrix; pipeline export)
- Customer wins (top 5 quotes / case-study material)
- Product roadmap (next 6 months)
- Material competitor moves
- Press coverage

## D. Decision-Ask Discipline

Every board meeting: 1-3 decisions explicitly asked. Format:

```
DECISION #1
Title: [single-line title]
Background: [context]
Options:
  A. [option A]
  B. [option B — recommended]
  C. [option C]
Recommendation: B
Rationale: [why B]
What's the ask: [approve B / advise on B vs C / weigh in by X date]
```

## E. African DFI-Specific Additions

When DFI is on cap table, add:

- ESG / impact dashboard (jobs created, smallholders reached, women / youth %, etc.)
- E&S risk monitoring
- Compliance with IFC Performance Standards
- Local-content reporting
- Reporting to DFI MIS in their format

## F. Living-Plan Cadence

| Cadence | What |
|---|---|
| Daily | KPI dashboard refresh (CFO) |
| Weekly | Pipeline + cash review |
| Monthly | Investor update; MBR internally |
| Quarterly | Board pack; full board meeting |
| Annually | Strategy refresh; new MSPOT; board offsite |

## G. Africa / Uganda Application Notes

- Many African boards have part-international, part-local members; provide pack in editable format that travels well, and assume async review.
- DFI directors / observers expect ESG / impact-monitoring in every quarterly pack.
- FX impact separated from operational performance (show local-currency + USD views).
- Ugandan Companies Act board-resolution and minute-keeping requirements must be met formally; embed in board secretariat.
- Public-sector / NGO concentration disclosed when >20% of ARR.
- Cultural norm: board meetings often include longer relational / social opening — budget time for this.
