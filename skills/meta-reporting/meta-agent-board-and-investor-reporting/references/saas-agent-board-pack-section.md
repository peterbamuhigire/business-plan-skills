# Quarterly Board Pack — Agent Section (Template)

Use this section in the quarterly board pack for any agent-product business. Append after the standard SaaS / AI sections.

## 1. Executive summary (one paragraph; plain English)

Plain-English description of the agent state this quarter: what the agent is doing, what's working, what's not, what's changing.

## 2. Full agent KPI trends (13-week)

Provide trend charts (or table if no charting) for:
- Resolved tasks per week
- Cost per resolved task (USD + local)
- Intervention rate %
- Task success rate %
- Agent gross margin %
- Agent ARR attribution
- Cache-hit ratio %
- HITL cost share %
- Tool cost share %
- Retry overhead share %
- Branch / loop breach count

Variance discipline: any KPI more than +/- variance threshold gets:
- Diagnosis (execution vs environment)
- Remediation
- Owner
- Deadline

## 3. Moat-vs-wrapper reassessment

- Latest 8-question rubric score (vs prior quarter)
- Changes per dimension
- Foundation-model commoditisation watch update
- Surviving-pieces inventory if provider ships in category
- Wardley-map refresh if structural shift

## 4. Autonomy expansion review

- Actions promoted from Class A -> B -> C -> D this quarter
- Pre-promotion eval coverage
- Drill outcomes for promoted actions
- AI Safety Lead sign-off
- Customer notification / consent if applicable

## 5. Drill cadence audit

- Monthly safety drills scheduled vs executed
- Quarterly tabletop exercise: scenario + outcome + gaps + remediation
- Kill-switch drill results
- Annual full simulation (if applicable this quarter)

## 6. Audit-log review summary

- Audit-log review meetings held
- Findings (count + severity)
- Regulator engagement (any audit-log requests)
- Audit-log retention policy compliance
- Immutability + queryability validated

## 7. Regulator engagement log

- Regulators engaged (ODPC / NDPC / NITA-U / Info Reg / NCSA / sectoral)
- Meetings / submissions
- New guidance / notices received
- Pre-clearance / sectoral approval progress
- Pending matters
- Risks identified

## 8. Stress-test refresh

- Provider 2x / 5x: impact today vs prior quarter
- Tool outage: simulation outcome
- Intervention rate 2x: simulation outcome
- Irreversibility incident at scale: reserve adequacy
- Foundation-model deprecation: migration plan status
- FX shock: corridor adequacy
- Regulator freeze: market exposure

## 9. Reserves

- Irreversibility reserve balance + months of coverage
- Model-migration reserve balance
- Regulator-engagement reserve balance
- Reserve adequacy assessment (vs expected incident rate)
- Top-up plan if needed

## 10. Talent retention signals

- AI Safety Lead retention status (in seat? signal? succession?)
- Eval Engineer retention status
- Agent Architect retention status
- Tool Engineer retention status
- HITL Designer retention status
- FDE retention status (if applicable)
- Compensation market scan results
- Diversity metrics

## 11. Foundation-model platform risk

- Provider trajectories in your category
- Provider product roadmap visibility
- Mitigation actions taken this quarter
- Moat-deepening progress

## 12. Bankability rescore (cross-reference)

- Aggregate score (vs prior quarter)
- Subscore movement per dimension
- Binding gaps
- Remediation progress

## 13. Valuation context

- Comparable transactions scan results
- Multiple range update
- Pre-money expectation for next round
- Stress on multiple under tail risks

## 14. Decisions taken (decision log extract)

- Material decisions this quarter (decision / alternatives / evidence / owner / review-date)
- Decisions due next quarter

## 15. Next-quarter agent priorities

- Top 3 priorities with measurable outcomes
- Dependencies and risks
- Resource requirements

---

## Notes for the author

- Keep board section to 5-10 pages with charts; appendix can hold raw data
- Cross-reference back to monthly investor updates (no surprises)
- Plain-English executive summary first
- Sev-1 incidents this quarter have a dedicated subsection with full postmortem
- Variance discipline applies throughout
- Make the reading order: state of agent -> changes -> risks -> reserves -> talent -> next-quarter
