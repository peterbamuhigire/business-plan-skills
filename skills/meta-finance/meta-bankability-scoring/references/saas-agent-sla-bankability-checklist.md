# Agent SLA Bankability Checklist

Scorecard for SLA-bearing agent businesses. Sits on top of the broader `saas-agent-bankability-checklist`. SLA bankability adds a 100-point scorecard across 7 SLA-specific dimensions.

---

## Dimension 1 — SLA Policy & Contract Discipline (0-15)

| Item | Points | Evidence |
|---|---|---|
| SLA policy memo documented (per pricing primitive) | 3 | Policy memo in data room |
| Contract-template SLA clauses standardised | 3 | Template + GC sign-off |
| SLA-credit cap clauses enforceable | 2 | Counsel opinion |
| Vendor-cost pass-through clause (>12 month contracts) | 2 | Coverage % of contract base |
| FX-corridor clause (local-currency / USD-cost) | 2 | Coverage % where applicable |
| Outcome-definition rigour (if outcome pricing) | 2 | Contract clause + verification process |
| Dispute-resolution SLA clause | 1 | Contract |

---

## Dimension 2 — SLA Performance & Telemetry (0-20)

| Item | Points | Evidence |
|---|---|---|
| Trailing 4-quarter performance data (uptime, accuracy, response, DoD) | 4 | Performance dashboard |
| Performance vs commitment trend visible | 3 | Trend chart |
| Telemetry architecture documented | 2 | Architecture diagram |
| SLA-breach detection automated | 2 | Alerting evidence |
| Per-customer / per-tier disaggregated reporting | 3 | Cohort report |
| Performance published externally | 3 | Status page / website |
| Auditor concurrence on telemetry integrity | 3 | Audit-firm letter |

---

## Dimension 3 — Reserve Methodology (0-15)

| Item | Points | Evidence |
|---|---|---|
| SLA-credit reserve methodology documented | 3 | Methodology memo |
| Reserve quarterly true-up cadence | 2 | True-up calendar |
| Refund-reserve methodology (if outcome pricing) | 2 | Methodology memo |
| Reserve adequacy: actuals vs reserve drawn trailing 4 quarters | 3 | Variance log |
| Reserve currency aligned to cost currency (or hedged) | 1 | FX policy |
| Auditor concurrence on methodology | 3 | Audit-firm letter |
| Catastrophic-scenario reserve factor in methodology | 1 | Methodology section |

---

## Dimension 4 — Financial Controls (0-15)

| Item | Points | Evidence |
|---|---|---|
| SLA-credit approval workflow with thresholds | 3 | Workflow doc + log |
| Refund approval workflow with thresholds | 2 | Workflow doc + log |
| Segregation of duties (telemetry vs accrual vs approval) | 2 | Controls matrix |
| Dispute-escalation workflow | 2 | Escalation matrix |
| SOC1 / SOC2 controls covering SLA-credit | 3 | Audit report |
| Audit-trail of credits / refunds issued | 2 | System log |
| Board notification trigger thresholds | 1 | Board calendar |

---

## Dimension 5 — Dispute & Gaming Discipline (0-10)

| Item | Points | Evidence |
|---|---|---|
| Dispute log maintained (count, aging, resolution) | 2 | Dispute register |
| Average dispute aging <14 days | 2 | Metric |
| <1% of revenue in dispute (trailing quarter) | 2 | Metric |
| Gaming-detection control (deviation from cohort) | 2 | Control documentation |
| Customer-success staffing scaled to dispute volume | 1 | Capacity model |
| Legal-bench capacity sized to escalation rate | 1 | Capacity / retainer |

---

## Dimension 6 — Regulator & Insurance Posture (0-10)

| Item | Points | Evidence |
|---|---|---|
| Sector-regulator engagement on SLA | 2 | Correspondence |
| SLA-relevant consultation responses filed | 2 | Submissions |
| Insurance coverage for SLA exposure (or self-insurance reserve) | 2 | Certificate / reserve memo |
| Carrier-exclusion monitoring | 1 | Annual broker review |
| Sovereign-AI provider SLA-pass-through clauses (if applicable) | 1 | Contract |
| Public-sector SLA delivery references (if applicable) | 2 | Reference |

---

## Dimension 7 — Investor / Auditor / DFI Readiness (0-15)

| Item | Points | Evidence |
|---|---|---|
| Data-room SLA section populated | 3 | Index complete |
| Pitch-deck SLA slide / paragraph ready | 2 | Deck |
| Quarterly investor-update SLA block standardised | 2 | Update history |
| Catastrophic-breach stress scenario in projection | 2 | Projection appendix |
| Peer-benchmark slide / paragraph | 2 | Benchmark library |
| FAQ rebuttal library (6 standard questions) | 2 | Rebuttal doc |
| Reconciliation across exec summary / projection / risk / valuation | 2 | Consistency check |

---

## Interpretation

| Total (out of 100) | Bankability |
|---|---|
| 0-29 | Not bankable for institutional agent fund or DFI on SLA dimension; rebuild discipline |
| 30-49 | Bankable for grant / strategic / DFI-with-conditions; SLA discipline build is primary use-of-proceeds |
| 50-69 | Bankable for Series A institutional agent fund or DFI; SLA narrative is "improving" |
| 70-84 | Bankable for Series B / vertical AI fund; SLA narrative is "confidence-builder" |
| 85-100 | Top-quartile institutional / growth-round ready; SLA is moat-relevant |

## Integration with the broader bankability stack

The SLA bankability scorecard is an **overlay** on top of:
- SaaS bankability scorecard (`meta-bankability-scoring/references/saas-bankability-scorecard.md`)
- AI bankability scorecard (in `meta-ai-bankability-and-investor-readiness/`)
- Agent bankability scorecard (in `meta-agent-bankability-and-investor-readiness/references/saas-agent-bankability-checklist.md`)

When the plan is an agent business with SLA commitments, **all four layers** are scored and reported separately. The SLA layer can be the swing variable for Series A / Series B / DFI rounds.

## Africa / Uganda Application Notes

- **Local audit firm coverage** — where Big-4 unavailable, mid-tier (BDO / Grant Thornton / Mazars / RSM / PKF / Crowe / Baker Tilly) auditor concurrence still earns Dimension 3 and 4 points
- **Insurance scarcity adjustment** — Dimension 6 self-insurance reserve substitutes where carrier coverage thin; document the substitution
- **Sovereign-AI provider clauses** — explicit row in Dimension 6; coverage materially relevant for African public-sector / regulated-sector deployments
- **FX-corridor clause** in Dimension 1 — promote to higher weight when local-currency revenue is dominant
- **DFI scrutiny** — IFC / AfDB / FMO / BII / Proparco / FCDO / USAID / GIZ DD teams test Dimensions 2, 3, 4, 6 specifically; weak score here disqualifies
- **Public-sector reference** — Dimension 6 public-sector references (Huduma / NIMC / Irembo / NITA-U / Home Affairs analogues) materially lift the score for agent businesses with public-sector ARR
- **Mobile-money settlement reliability** — record as part of telemetry (Dimension 2) for per-resolution / per-outcome agents
