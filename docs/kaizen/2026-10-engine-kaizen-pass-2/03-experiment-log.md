## Attempts that were reverted before commit (E10 detail)

1. **First `00-plan-assembly` description** ("Use when approved plan sections already exist and must be ordered..."): the existing fixture `positive-assembly` regressed (the skill dropped out of the top three) because the description lost the words "plan assembly" that the lexical scorer and a user's request both contain. Rewritten.
2. **Second attempt** ("Use for plan assembly once approved sections exist: order them..."): a colon followed by a space made the YAML frontmatter unparseable. The routing script silently skipped the skill ("expected skill `00-plan-assembly` is not active", 78/80), which is how the silent-skip defect was found. The description was reverted and the script fixed so it now fails and names the file (test `test_skill_with_unparseable_frontmatter_is_reported_not_silently_dropped`).
3. **Third attempt** ("Use when plan assembly is needed because approved sections already exist..."): kept; 80/80.

Fixture candidates that failed top-three were reworded in natural language (for example "Ugandan" to "Uganda", "bankable" to "bankability"), not by adding vocabulary to skills. Three candidates exposed real routing weakness: a natural "three-year income statement, cash flow and balance sheet for the bank loan" prompt did not reach `10-financial-projections` in the top three until its description was specific. 48 of 137 skills still share the template description (see `06-next-cycle.md`).
